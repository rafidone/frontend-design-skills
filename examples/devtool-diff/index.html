01 — The brief

A review brief, not another diff viewer.

Kestrel reads the shape of a change before you read the lines. It groups files by intent, flags the risky edges and links each group to the test that covers it.

  1. 01

    Groups that mean something.

    Files are clustered by the change they make, not the folder they live in. The parser guard and its test sit together.

    guard.tsguard.test.ts↳ test
  2. 02

    The edges come first.

    Migrations, public API changes and missing tests surface above formatting noise. Risk is a position in the brief, not a badge you have to hunt for.

    public API1 callerwhitespace hidden
  3. 03

    A test for the claim.

    Each group points at the test that proves it, or says plainly that no test exists yet. A gap is reported as a gap.

Does Kestrel send my code anywhere?

No. The parser and the index run locally. Network access is only used for update checks, and can be disabled.

Which languages are supported?

TypeScript, JavaScript, Python, Go and Rust today. A language without a parser still gets a file-and-test brief.
