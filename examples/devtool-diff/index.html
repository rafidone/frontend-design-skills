A review brief, not another diff viewer.

Kestrel reads the shape of a change before you read the lines. It groups files by intent, flags the risky edges and links each group to the test that covers it.

Kestrel surfaces migrations, public API changes and missing tests before the formatting noise.

Does Kestrel send my code anywhere?

No. The parser and the index run locally. Network access is only used for update checks, and can be disabled.

Which languages are supported?

TypeScript, JavaScript, Python, Go and Rust today. A language without a parser still gets a file-and-test brief.
