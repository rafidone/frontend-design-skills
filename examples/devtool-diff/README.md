extending this build; do not add a second of any.

## Run

```bash
python3 -m http.server 4173 --directory .
# open http://127.0.0.1:4173
```

## Build

There is no build step. The files are already the production output.

## Verify

Serve the built output over HTTP, then run the gate from this example directory:

```bash
node /path/to/frontend-design-skills/scripts/verify.mjs . --full --kind devtool
```

Screenshots, `report.json`, `report.html` and `report.md` are written under
`.frontend-design-skills/runs/`.

## Assets

Icons, mock data and diagrams are local under `assets/`. This build uses no
photographs, so it ships no photo manifest; every visual is CSS or a local SVG
and needs no third-party attribution. Credits are recorded in `credits.html`.

## Notes

- The page is static at runtime. The framework adapter must keep the same tokens,
  container and component names as the HTML reference.
- Replace the demo copy and demo interactions with the client's real content
  before delivery.
- Delete unused photographs and mock data rather than shipping a larger bundle.
