02 — The room

A neighbourhood place, not a concept.

Open since 2019, on the same corner, with the same two ovens. The room was built around a window and a bench long enough for four.

Nothing here changes with the season except the fruit in the case. The regulars know which stools catch the morning light; visitors find them by mid-morning.

We keep the back table unreserved. If you need an hour with a book and a second cup, it is yours for the asking.

“I come for the bread and stay for the quiet. There is nowhere else I can read for an hour without being moved along.”

Marta Silva — Regular, Príncipe Real

The back table is never booked twice. Ask at the counter when you arrive.
